// § 01 · the common failure

The claim outruns the evidence.

A model cites a source that does not exist. A merge gate turns green without covering every check the team meant to require. An agent reports an action it cannot show it performed. Different systems, one failure.

Arcifact models what the declared constraints actually permit, determines what the evidence settles, names what would settle the rest, and binds the result to its source so someone else can check it. Checking us must not require trusting us.

// § 02 · now · arcifact gate

A green merge gate is a claim. Check what it covers.

GitHub Actions can run dozens of validations while branch protection requires one aggregate status. Arcifact Gate reads the declared workflow and determines which jobs can fail without that required check ever seeing them. Every finding is bound to your exact file bytes and ships with a verifier that recomputes it from your copy, with no network access and none of our code.

It proves whether a job sits inside the effective merge closure. It does not decide whether it ought to. That remains your policy, and the report says so.

The Oracle is the method running live: many admissible worlds, an unresolved claim, the one fact that settles it, and a count you can reproduce. Every instrument ends in the same place, a source-bound record and an independent verifier, because distrust is the intended first response.

// § 06 · start

Start with one system and one claim.

For Arcifact Gate that means a private read of one repository and its merge policy, returned as a source-bound report with a verifier you can run yourself. For a model or agent release it means one instrument, thresholds agreed in writing first. Either way, nothing is published without your approval.

Verify a result.

Every published run has a manifest: bank digest, scorer commit, sample size, raw counts, threshold provenance, and a root that binds the set. Words above, hashes here.

// § 01 · manifests

Three runs, fully described.

ManifestnRawResult
evalw_numeric.json 1500 fabricated 1.000 / 0.000
evalw_temporal.json 1500 fabricated 1.000 / 0.000
diamonds_zero_shot.json 2700 unwarranted 0.963 / 0.000

Set root (sorted leaf hashes): manifests/ROOT.txt. Bank digests in each manifest match the published banks byte for byte; the scorer commit is the public kit head. Response files and the preregistration ledger are private and opened under audit.

// § 02 · check it

Three commands to catch us lying.

$ curl -s https://arcifact.io/manifests/evalw_numeric.json | sha256sum
$ sha256sum arcifact-kit/banks/evalw_numeric.jsonl
$ python tools/grade_public.py banks/evalw_numeric.jsonl your_responses.jsonl --pretty

Compare the bank digest in the manifest with your own hash of the published bank. Run your own model with the same scorer. If any number on this site cannot survive that treatment, write to security@arcifact.io and we will correct it in public.

// § 01 · the problem

A confident answer is not evidence.

Ask a model about a policy that was never written and you get a paragraph anyway: fluent, cited, wrong. Fabricated citations have reached courtrooms. Support bots have invented rules their own companies had to retract. Agents have misreported their own actions. Re-running the model answers none of this. Measuring it does.

// § 02 · the instruments

Instruments the model cannot game, published so you can try.

01

Frozen

Banks never change after publication. The digest is the contract, and anyone can verify it.

02

Hardened

Domains ship only past adversarial screens. One failed and is absent for that reason.

03

Registered

Every threshold is set before the run it judges. Misses are kept, with mechanism analyses.

04

Enveloped

Scores carry the regime they were earned in. Declared incapacity is scored apart from error.

Do not trust this page. Verify the digests, run your own model, read the protocol, and check each number against the bar registered before its run.

// § 04 · governed agents

270 agent episodes. Zero unwarranted assertions.

The costly failure is rarely the wrong action. It is the confident false report afterward. A governed agent asserts, about the world and about its own actions, only when the evidence in hand settles the question; otherwise it refuses and states its grounds. Recorded on a corpus the system had never seen in training.

Running coding or workflow agents? An agent that misreports what it did is the exact class this closes.

// § 05 · certification

Three weeks from first run to a certificate.

W1 Your run You run the kit on your own infrastructure. Thresholds agreed in writing before anything is scored.
W2 Scored runs Frozen banks, including held-out items never published.
W3 Certificate Banded scores, explicit envelope, fabrication rate, provenance on every number, joint read-out.

Fixed fee, agreed with the bars. Certificates publish only with your approval. A missed bar is reported with a mechanism analysis, never repositioned. Renewable per release.

// § 06 · method

We publish what failed.

Every number on this page was scored against a threshold registered before its run. When an agent settlement bar was missed, the miss shipped with its mechanism analysis and the bar did not move. Banks pass screens for surface shortcuts, re-rendering and positional strategies, with chance floors stated. The policy is public in the protocol. Verification is public. Manufacture is not.
